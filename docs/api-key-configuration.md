# 直接输入 API 密钥

更新：2026-10-26。系统设置的「模型 API 连接」改为填写 API 密钥，不再要求用户创建环境变量。

## 使用方式

填写连接名称、API 协议、端点、模型标识和密钥后保存。密钥输入框采用密码模式，成功后清空；连接列表不显示密钥或内部凭据引用。编辑连接会创建新版本，需要重新输入密钥，既有 Agent 和运行快照继续使用原版本。保存连接不会发送模型请求；「发送真实模型验证请求」才会调用目标服务。

## 保存与兼容

Host 为每个新连接生成独立凭据引用，通过官方 DSH `credentials-local` 保存密钥。业务数据库与连接响应只存引用，模型适配器在请求时从凭据服务读取，不向进程环境变量写入密钥。凭据服务使用 Host 的 `$DSH_HOME/.credentials.yaml` 文件，支持重启恢复；这是 Host 凭据文件，不是加密保险库。请按原有 Host 目录权限管理该文件。

两份标准 RIFT 启动配置均挂载凭据服务，Host 在服务就绪后启动。旧 `credentialRef` 环境变量连接继续兼容，新接口要求 `apiKey` 与 `credentialRef` 二选一。创建失败时删除本次生成的凭据，不修改已有版本。提交密钥会在校验、错误和幂等回执处理前注册脱敏；前端保存不使用以完整请求正文为键的通用缓存。
