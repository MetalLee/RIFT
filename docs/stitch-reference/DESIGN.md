# Design System: RIFT — 以聊天为中心的多 Agent 工作区 (Claude 纯净版)
> 版本：UI v3 · Claude 纯净温润版 · 2026-10-25
>
> 用途：Google Stitch 页面生成与前端高保真实现的设计依据。
>
> 核心风格演进：基于用户反馈从最初的高密度深色工程监控台，全面进化至 **Claude 风格（高留白、温润燕麦暖石底色、赤陶红强调、极低信息密度、去噪音化双列布局）**。全套 8 个界面统一外层 Shell 框架与视觉语言。

---

## 1. 核心视觉主题与氛围 (Visual Theme & Atmosphere)

RIFT 是以聊天为核心的多 Agent 协同开发工作区。界面汲取 Claude 官方出版物级别的阅读体验与优雅质感，彻底消除传统开发者工具中冰冷压抑的纯黑界面和冗余堆砌的密集图表。

- **信息密度 (Density 4/10)**：大幅度拉开呼吸间距，正文与对话拥有主导性的舒缓排版空间；将原先常驻的繁琐状态指标渐进式收敛至顶部状态胶囊或按需展开面板中。
- **视觉层级 (Variance 4/10)**：左侧精炼导航栏（232px）+ 居中沉浸式工作流区域，彻底消除右侧常驻的沉重仪表盘，告别卡片墙与多重边框压迫感。
- **色彩与质感 (Warm Stone & Terracotta)**：采用典雅柔和的暖石纸白背景（`#FAF9F5`）与高可读性的暖炭灰正文（`#211F1D`），搭配 Claude 标志性的陶土红（`#CC6B49`）作为核心点睛色。
- **动效节奏 (Motion 3/10)**：极其克制温和的微交互，仅在实际运行或待处理的关键节点呈现呼吸微点，无花哨发光与多余旋转动画。
- **产品语言**：全中文为主，保留开发者熟悉的专业技术词（Agent、Skill、Worktree、SSE、Commit 等）。所有原型测试数据均明确标示「(示例)」。

全面遵循 Claude 纯净浅色调色板，杜绝纯黑（#000000）、高饱和荧光色和渐变大字。

## 3. 字体与排版规范 (Typography Rules)

- **主文本字体**：优先采用优雅的无衬线字体（Geist、Newsreader、Noto Sans SC、系统无衬线回退）；
- **等宽技术字体**：Geist Mono、Cascadia Code、Consolas、monospace，专用于分支名、Worktree 路径、Commit SHA、状态码与代码块；
- **排版比例**：
  - 页面主标题：24px - 28px，字重 600，行高 1.3；
  - 章节与卡片标题：16px - 18px，字重 600；
  - 对话流与正文：15px - 16px，行高 1.65 - 1.7，文字块最大宽度约 65ch（舒适杂志阅读宽度）；
  - 标签与微型元数据：12px - 13px，字重 500；
- **严格禁忌**：严禁使用通用 Emoji，图标采用精致的 18px 线性微图标；严禁刺眼的纯黑文字与彩虹色标签堆砌。

## 4. 全套 8 个界面（Claude 纯净版）清单与规范标准

全套界面均基于同一持久化外壳（Shell：左侧导航 + 顶部面包屑与状态胶囊）：

| 页面编号 | 页面名称 | 页面职责与设计落地规范 |
| :--- | :--- | :--- |
| **UI-01** | **工作区管理与创建** | 集中展示多工作区切换与管理卡片（如「RIFT 界面组 (当前活动)」、「执行引擎/宿主核心」），提供极简的拓扑示意图与右侧「创建新工作区」抽屉，保持纯净克制。 |
| **UI-02** | **聊天首页** *(基准原型)* | 整个系统的视觉焦点。双列通透排版，顶部状态收缩为极简胶囊，中心 760px 沉浸式对话阅读流，底部大圆角浮动输入舱（集成 @ 智能体唤起与发送）。 |
| **UI-03** | **主 Agent 配置** | 协调者（Master Coordinator）的核心设置页面。清晰呈现模型 API 直连 vs 本地宿主运行时双模插拔、密钥引用与生效范围快照机制。 |
| **UI-04** | **智能代理 Agent** | 团队协作成员列表（协/界/接/回）。采用杂志级单字徽章，仅保留职责摘要、模型宿主与配置按钮，剔除繁杂图表与多色杂乱标签。 |
| **UI-05** | **技能扩展 Skill** | 双栏杂志级排版。左侧为工作区共享与专属规范列表（代码约定、交互规范），右侧呈现高可读性的 Markdown 契约预览与版本签名。 |
| **UI-06** | **代码库与工作区** | 多仓库分组（rift-web、rift-host）。提炼出 Git Worktree 独立工作目录与独占锁机制，提供清晰的改动统计与「在编辑器打开」便捷动作。 |
| **UI-07** | **任务队列** | 任务流水线看板。顶部离散进度指示（3/5 就绪），左侧清晰的任务状态卡片，右侧为验收准则清单（Acceptance Criteria）与决策门禁。 |
| **UI-08** | **Agent 状态面板** | 针对 Agent 运行时的独立投影面板。将状态分为「需关注事项」「工作中」「就绪与空闲」，附带轻量资源开销说明，通透清爽。 |

## 5. 交互契约与防误设计 (Anti-Patterns & Principles)

1. **统一外壳一致性**：所有界面均共享相同的左侧导航栏（工作区切换器、新建对话、导航项：对话、智能代理、技能扩展、代码库与工作区、任务队列、系统设置）与顶部面包屑；
2. **渐进式展开，杜绝卡片墙**：不在首页或子页面直接平铺底层基础设施监视器；通过详情抽屉、预览面板或快捷按钮按需调用；
3. **真实证据替代虚假进度**：进度始终使用离散任务完成数（例如 `3 / 5 项已就绪`），不通过耗时推算虚假百分比；
4. **单消息接收者契约**：每条对话消息通过主 Agent 默认接收或 @ 单一子 Agent 定向派发，确保职责单一清晰；
5. **所有原型数据严格标注**：页面中所有演示分支、任务编号、代码示例均显式附带 `(示例)` 标识。
