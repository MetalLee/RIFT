关于 Git Worktree 隔离机制

RIFT 会自动为每个并发执行代码任务的 Agent 创建独立的工作树与隔离分支。所有物理写操作均被限制在其绑定的工作目录内，主分支与其它 Agent 的改动保持严格解耦，杜绝 Git 脏读写与 stash 冲突。
